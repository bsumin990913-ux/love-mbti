아직 저장소가 연결되지 않았어요

아래 순서로 한 번만 연결하면 모든 기기의 검사 결과가 여기 모여요. 연결 전까지는 이 브라우저에 남은 기록만 볼 수 있어요.

  1. Vercel 프로젝트 → Storage → Marketplace 에서 Upstash for Redis 를 만든다
  2. 이 프로젝트에 연결하면 KV_REST_API_URL, KV_REST_API_TOKEN 이 자동으로 들어간다
  3. Settings → Environment Variables 에서 ADMIN_PASSWORD 를 직접 추가한다
  4. 다시 배포(Redeploy)한다
